# Next Year’s Monsters™ Visual Freeze Contract

TS: 2026-08-16 07:44 ET

## Purpose
When a visual area is approved and working, it is frozen. Automated maintenance may monitor it but must not redesign, resize, reposition, relabel, restyle, or restructure it without explicit user approval for that exact visual change.

## Frozen visual areas
- Homepage hero composition, including Captain Breakout™ on the bull, headline, fingerprint, search area, buttons, spacing, and overall balance.
- Captain Breakout™ artwork and approved placement.
- Detective Break™ artwork and approved placement.
- Approved left-column / right-column page structures and page widths.
- Approved typography, spacing, navigation placement, and major section order.
- Start Here visual structure.
- Monster Check visual structure.
- Monster Hunt visual structure.
- The System visual structure.
- VCL™ Library visual structure.
- Homepage ticker presentation: compact three-line TradingView presentation showing company name, price, and daily change, approximately 70px vertical clearance, with the far-right label OPEN MARKET EXPLORER.

## Allowed automatic changes
Automated work may continue on invisible or functional plumbing when it does not alter frozen visuals, including:
- live-data freshness and provider status;
- SEC/data connections;
- API/deployment reliability;
- ticker routing and broken links;
- stock-score consistency and data integrity;
- background verification and monitoring.

## Visual defect rule
If monitoring finds a visual defect in a frozen area, report it. Do not repair or redesign it automatically. A visual change requires explicit user approval.

## Restoration rule
If a frozen visual regresses, prefer restoring the last approved version from Git history rather than recreating it from memory.
