# Deployment Boundary

## Can be done with the current package

- Preview the website locally.
- Upload it to a new GitHub repository.
- Publish a GitHub Pages preview.
- Replace the approved image and audio without changing the code.
- Expand the stock demo data.

## Cannot be completed without another connection

- Publishing directly to the existing `NextYearsMonsters.com` hosting account.
- Changing DNS records.
- Connecting live stock data.
- Storing users, emails, watchlists, payments, or alerts.
- Generating responsible live Monster Ratings™ without a defined formula and licensed data API.
